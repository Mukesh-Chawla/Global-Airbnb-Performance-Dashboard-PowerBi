# 🌍 Global Airbnb Performance Dashboard | Power BI

- Airbnb has become a global leader in short-term rental bookings, offering a wide range of accommodations, from apartments to villas and more.
  In this project, I developed a Power BI dashboard to visually analyze Airbnb data, aiming to provide clear insights into booking patterns, accommodation preferences, and other significant metrics.


## 📌 Project Overview

- The **Global Airbnb Performance Dashboard** is an interactive Power BI dashboard designed to analyze Airbnb listings across multiple locations. 
  Using a dataset sourced from Kaggle, this project provides insights into listing performance, pricing trends, host activity, customer ratings, and property distribution to support data-driven decision-making.


## 📊 Dashboard Features

- 📌 Total Listings
- 💰 Average Price
- ⭐ Average Weighted Score
- 👤 Total Hosts
- 🏙️ Top Cities by Number of Listings
- 🏠 Room Type Distribution
- 🏡 Property Type Analysis
- 📅 Overall Ratings by Cities
- 📈 Host Quality
- 🎛️ Interactive Filters (Slicers)

## 💡 Key Insights

- In **2015**, Airbnb reached **highest** number of new listings. 2016 and 2017 saw a restraint also due to tightening in local regulations. From 2018, there was a new growth stopped in 2019 by the **COVID-19 pandemic**.
- **Paris**, **NYC**, and **Sydney** account for almost half of the total listings. **Paris** is the city with the **most listings**, a possible driver is the **prices** for hotel rooms being twice as much as Airbnb.
- **Superhosts** outperform **Non-Superhosts** with an average weighted score of **9.9** vs. **9.6**, reflecting stronger guest satisfaction and service consistency.
- **Mexico City** and **Rio de janeiro** are the overall best rated cities, **Hong Kong** and **Istanbul** the worst ones. **Cleanliness** and **value for money** ratio are the the two metrics generally scoring the **lowest** and **Communication** is the **highest**.
- The majority of hosts **(66.92%)** are **verified** and have profile pictures, indicating **strong** adoption of **trust-building practices**. However, **32.66%** of hosts are **not verified** despite having profile pictures, highlighting an opportunity to improve host verification compliance and platform trust.
